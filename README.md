# Diamond Glow Mod

Make diamonds glow and seeable through walls in Minecraft.

## Features

- Makes diamonds glow in the inventory and world
- Toggle glow effect with a keybind (Right Shift)

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.11 or later
- Fabric API 0.96.11 or later

## Installation

1. Download the mod JAR file from the [Releases](https://github.com/EnderDevelopment/diamond-glow-mod/releases) page.
2. Place the JAR file in your Minecraft `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

- Press Right Shift to toggle the glow effect on and off.

## Configuration

The mod does not have a configuration file. The glow effect can only be toggled with the keybind.
